# Simple Interest Calculator

**Author: Amir Kabdilmalik (Amir888-s)**

A Bash calculator that computes simple interest from a principal amount, an annual interest rate, and a time period in years. This project demonstrates Git and GitHub collaboration for the final course assignment.

## Formula

Simple interest = principal × annual interest rate × time in years / 100.
Enter the annual rate as a percentage: enter 5 for 5%.

## Run

Requires Bash and awk (available in Git Bash on Windows).

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted. Nonnegative integer and decimal values are accepted.

Example: principal 1000, annual rate 5, and time 2 produce interest of 100.00.
